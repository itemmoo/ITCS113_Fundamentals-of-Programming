# Hollow Diamond

Write a program that reads an odd integer `n` and prints a hollow diamond whose widest width is `n`.

Let the center be at row `(n+1)/2`.

- The diamond outline is made of `*`
- Inside the diamond is space `' '`
- Outside the diamond is also space `' '`

## Input
One odd integer `n` (`3 <= n <= 99`).

## Output
`n` lines, each with exactly `n` characters.

## Example
Input
```
7
```

Output
```
   *   
  * *  
 *   * 
*     *
 *   * 
  * *  
   *   
```
