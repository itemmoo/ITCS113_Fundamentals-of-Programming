# Temperature Level

Write a C program that reads an integer temperature (in Celsius)
and prints its level according to the following rules:

- If temperature < 10       → print "Cold"
- Else if temperature < 25  → print "Warm"
- Else                      → print "Hot"

## Input
An integer representing temperature in Celsius.

## Output
Print exactly one word:
Cold, Warm, or Hot

<hr>

**Case 1: Cold**

Sample input:
```
5
```

Sample output:
```
Cold
```

**Case 2: Warm**

Sample input:
```
20
``` 

Sample output:
```
Warm
``` 

**Case 3: Hot**
Sample input:
```
30
``` 

Sample output:
```
Hot
```
