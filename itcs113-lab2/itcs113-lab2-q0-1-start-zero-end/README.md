# Start-Zero-End

Write a program that reads one integer `n` and prints:

1. Print `Start` on the first line.
2. **If** `n` is exactly `0`, print `Zero` on the next line.
3. Print `End` on the last line.

**Input**: one integer `n`.

**Output**:
- Always print `Start` and `End`.
- Print `Zero` **only when** `n == 0`.

<hr>

**Case 1: n is not zero**

Sample input:
```
4
```

Sample output:
```
Start
End
```

**Case 2: n is zero**

Sample input:
```
0
```

Sample output:
```
Start
Zero
End
```
