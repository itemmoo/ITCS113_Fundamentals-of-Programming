# Negative Range

Write a program that reads one integer `x` and prints:

- If `x >= 0`, print `NonNegative`
- Else (`x < 0`):
  - If `x < -100`, print `TooSmall`
  - Otherwise, print `Negative`

**Input**: one integer `x`.

**Output**: exactly one word from the rules above.

<hr>

Sample input:
```
-150
```

Sample output:
```
TooSmall
```
