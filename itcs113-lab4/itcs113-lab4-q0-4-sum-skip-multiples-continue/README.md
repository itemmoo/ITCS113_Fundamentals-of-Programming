# Sum 1..n but Skip Multiples

Write a program that reads two integers `n` and `k` (`n >= 1`, `k >= 1`) and computes the sum of integers from `1` to `n`
**excluding** the numbers that are multiples of `k`.

Print the sum.

IMPORTANT: You MUST use the `continue` statement to do this exercise.

Example: if `n = 10` and `k = 3`, you sum `1 + 2 + 4 + 5 + 7 + 8 + 10`.

<hr>

**Case 1**

Sample input:
```
10 3
```
Sample output:
```
37
```

**Case 2**

Sample input:
```
5 1
```
Sample output:
```
0
```

**Case 3**

Sample input:
```
1 2
```
Sample output:
```
1
```
