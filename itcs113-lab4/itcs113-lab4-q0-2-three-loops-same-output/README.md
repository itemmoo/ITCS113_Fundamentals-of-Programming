# Three Loops, Same Output

Write a program that reads an integer `n` (`n >= 1`) and prints the numbers from `1` to `n` **three times**:

1) using a `while` loop  
2) using a `for` loop  
3) using a `do-while` loop  

Each line must have the format:

`<loop_name>: 1 2 3 ... n`

Use exactly one space between numbers, and no trailing space at the end of the line.

<hr>

**Case 1**

Sample input:
```
5
```
Sample output:
```
while: 1 2 3 4 5
for: 1 2 3 4 5
do-while: 1 2 3 4 5
```

**Case 2**

Sample input:
```
1
```
Sample output:
```
while: 1
for: 1
do-while: 1
```
