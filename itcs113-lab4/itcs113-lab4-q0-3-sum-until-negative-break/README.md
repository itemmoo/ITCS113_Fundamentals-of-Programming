# Sum Until Negative

Write a program that reads integers from input and computes the sum of all **non-negative** numbers.

Stop reading as soon as a **negative** number is encountered (do not include that negative number in the sum).

Then print the sum.

IMPORTANT: You MUST use the `break` statement to do this exercise.

Notes:
- There will be at least one negative number in the input (so the program always stops).
- You may assume the sum fits in a 64-bit signed integer.

<hr>

**Case 1**

Sample input:
```
1 2 3 -1
```
Sample output:
```
6
```

**Case 2**

Sample input:
```
0 0 5 10 -7
```
Sample output:
```
15
```

**Case 3**

Sample input:
```
-5
```
Sample output:
```
0
```
