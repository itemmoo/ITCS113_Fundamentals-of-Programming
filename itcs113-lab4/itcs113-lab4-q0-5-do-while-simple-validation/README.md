# Simple Input Validation (Do-While)

Write a program that keeps reading integers until it gets a **valid** integer `x`.

A valid `x` must satisfy:

- `1 <= x <= 10`

Your program must use a **do-while loop** for the validation.

After reading a valid `x`, print:

`x count`

where `count` is the number of integers read (including the valid one).

<hr>

**Case 1**

Sample input:
```
5
```
Sample output:
```
5 1
```

**Case 2**

Sample input:
```
-3 0 11 7
```
Sample output:
```
7 4
```

**Case 3**

Sample input:
```
100
10
```
Sample output:
```
10 2
```
