# Do-While Countdown

Write a program that reads an integer `n` (`n >= 0`) and prints a countdown from `n` down to `0`.

Print one integer per line.

**Important:** Your program must print `0` even when `n` is `0`.

<hr>

**Case 1**

Sample input:
```
5
```
Sample output:
```
5
4
3
2
1
0
```

**Case 2**

Sample input:
```
0
```
Sample output:
```
0
```
