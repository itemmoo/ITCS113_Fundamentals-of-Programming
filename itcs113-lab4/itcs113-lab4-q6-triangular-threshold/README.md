# Triangular Threshold

Write a program that reads an integer `n` (`n >= 1`).

Find the smallest positive integer `k` such that:

`1 + 2 + 3 + ... + k >= n`

Then print `k` and the sum `S = 1 + 2 + ... + k` on one line in the format:

`k S`

<hr>

**Case 1**

Sample input:
```
1
```
Sample output:
```
1 1
```

**Case 2**

Sample input:
```
10
```
Sample output:
```
4 10
```

**Case 3**

Sample input:
```
11
```
Sample output:
```
5 15
```
