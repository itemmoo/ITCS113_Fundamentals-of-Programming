# Multiples of 3

Write a program that reads an integer `N` and prints all numbers from `1` to `N` (inclusive) that are divisible by 3.

- Print the numbers on **one line**, separated by a single space.
- If there is no such number, print `none`.

<hr>

Sample input:
```
10
```

Sample output:
```
3 6 9
```
