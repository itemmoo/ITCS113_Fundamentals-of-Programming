# Sum Until Zero

Write a program to read integers (one per line) until the user enters `0`.

After `0` is entered, print:

1. `count: X`  (how many numbers were read before the zero)
2. `sum: Y`    (the sum of those numbers)

**Note:** The terminating `0` is not included in the count or the sum. The numbers can be negative.

<hr>

Sample input:
```
5
-2
7
0
```

Sample output:
```
count: 3
sum: 10
```
