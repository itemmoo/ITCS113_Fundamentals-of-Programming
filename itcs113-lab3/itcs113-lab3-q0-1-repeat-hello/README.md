# Repeat Hello

Write a program that reads an integer `K` and prints the word `Hello` exactly `K` times.

Each line must be in the format:

`Line i: Hello`

where `i` starts from 1.

**Note:** If `K` is 0, print nothing.

<hr>

Sample input:
```
3
```

Sample output:
```
Line 1: Hello
Line 2: Hello
Line 3: Hello
```
