# Digit Frequency Counter

Read an integer `n` followed by `n` digits (each digit is between 0 and 9).
Count how many times each digit appears.

## Input
- First line: integer `n` (1 ≤ n ≤ 200)
- Second line: `n` integers, each in [0, 9]

## Output
Print 10 integers: counts of digits 0, 1, 2, ..., 9 (in this order), separated by a single space.

## Example
Input:
```
8
1 2 1 0 9 9 9 2
```

Output:
```
1 2 2 0 0 0 0 0 0 3
```
