# Sum of Even Values

Read an integer `n` followed by `n` integers. Compute the sum of the **even** values (divisible by 2) and print the sum.

## Input
- First line: integer `n` (1 ≤ n ≤ 50)
- Second line: `n` integers

## Output
Print the sum of the even values.

## Example
Input:
```
6
1 2 3 4 5 6
```

Output:
```
12
```
