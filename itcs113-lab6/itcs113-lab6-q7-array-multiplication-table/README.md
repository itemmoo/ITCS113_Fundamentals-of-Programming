# Array Multiplication Table

Read an integer `n` and an array `a` of size `n`.
Print an `n × n` table where the value at row `i` and column `j` is `a[i] * a[j]`.

## Input
- First line: integer `n` (1 ≤ n ≤ 20)
- Second line: `n` integers

## Output
Print `n` lines, each with `n` integers separated by a single space.

## Example
Input:
```
3
2 5 -1
```

Output:
```
4 10 -2
10 25 -5
-2 -5 1
```
