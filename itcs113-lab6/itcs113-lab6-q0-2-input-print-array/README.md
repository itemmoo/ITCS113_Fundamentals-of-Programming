# Input and Print Array

Read an integer `n` followed by `n` integers. Store them in an array, then print them in the same order.

## Input
- First line: integer `n` (1 ≤ n ≤ 20)
- Second line: `n` integers

## Output
Print the `n` integers in the same order, separated by a single space.

## Example
Input:
```
5
10 20 30 40 50
```

Output:
```
10 20 30 40 50
```
