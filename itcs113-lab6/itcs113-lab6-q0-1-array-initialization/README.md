# Array Initialization

Create an integer array `a` of size **5** with the following initial values:

`3 1 4 1 5`

Then print the array elements in order on **one line**, separated by a single space.

## Input
No input.

## Output
Print the 5 numbers separated by one space.

## Notes
- Print a newline at the end.

## Example Output
```
3 1 4 1 5
```
