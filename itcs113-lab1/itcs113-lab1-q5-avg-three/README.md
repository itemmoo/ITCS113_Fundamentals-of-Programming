# Calculate the Average of the Three Numbers

## Instruction

Write a program to compute and display the average of three float from input.
The output should be in 2-decimal places.

## Examples

### Example 1

Input:

```plaintext
-1.5
0
1.5
```

Expected output:

```plaintext
The average is 0.0
```

### Example 2

Input:

```plaintext
5.0
12
13
```

Expected output:

```plaintext
The average is 10.0
```
