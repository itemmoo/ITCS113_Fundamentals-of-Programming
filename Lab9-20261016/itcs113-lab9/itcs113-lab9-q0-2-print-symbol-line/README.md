# Print a Symbol Line with a Void Function

Write a program that reads an integer `n` and a character `ch`, then uses a self-defined function named `print_line` to print `ch` exactly `n` times.

## Requirements
- Define the function `print_line`.
- The function must have return type `void`.
- The function must receive two parameters: `n` and `ch`.
- After printing the characters, print a newline.
- You may assume `n >= 0`.

## Function Prototype
```c
void print_line(int n, char ch);
```

## Input
One integer `n` and one character `ch`.

## Output
Print the character `ch` repeated `n` times on one line.

### Sample Input
```
5 #
```
