# Circle Area Function

Write a program that reads the radius of a circle and uses a self-defined function named `circle_area` to compute the area.

Use the formula:

```
area = 3.14159 * r * r
```

## Requirements
- Define the function `circle_area`.
- The function must receive one `float` parameter.
- The function must return a `float`.
- Print the answer with 2 decimal places.

## Function Prototype
```c
float circle_area(float r);
```

## Input
One real number `r`.

## Output
Print the area with 2 decimal places.

## Sample
### Sample Input
```
2.5
```

### Sample Output
```
19.63
```
