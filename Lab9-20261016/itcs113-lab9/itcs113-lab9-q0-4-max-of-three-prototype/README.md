# Maximum of Three Numbers

Write a program that reads three integers and uses a self-defined function named `max_of_three` to return the largest value.

You need to determine the return type, function name, and parameters of the function `max_of_three` based on the function call given in the main.c file.


## Input
Three integers `a`, `b`, and `c`.

## Output
Print the largest integer.

## Sample
### Sample Input
```
9 4 7
```

### Sample Output
```
9
```
