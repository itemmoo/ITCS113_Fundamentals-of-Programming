# Add Two Integers Using a Function

Write a program that reads two integers and uses a self-defined function named `add_two` to return their sum.

## Requirements
- Define the function `add_two`.
- The function must receive two integers.
- The function must return the sum as an integer.
- Print the result followed by a newline.

## Function Prototype
```c
int add_two(int a, int b);
```

## Input
Two integers `a` and `b`.

## Output
Print one integer: the sum of `a` and `b`.

## Sample
### Sample Input
```
8 15
```

### Sample Output
```
23
```
