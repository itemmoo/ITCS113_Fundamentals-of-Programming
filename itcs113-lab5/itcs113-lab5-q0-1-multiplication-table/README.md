# Multiplication Table

Write a program that reads an integer `n` and prints an `n × n` multiplication table.

- The value at row `i` and column `j` is `i * j` (where `i` and `j` start from 1).
- Print each row on its own line.
- Separate numbers in the same row with exactly one space.

## Input
One integer `n` (`1 <= n <= 9`).

## Output
`n` lines, each containing `n` integers.

## Example
Input
```
4
```

Output
```
1 2 3 4
2 4 6 8
3 6 9 12
4 8 12 16
```
