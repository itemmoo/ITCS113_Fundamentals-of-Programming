# Right Triangle (Stars)

Write a program that reads an integer `n` and prints a right triangle of `*` with height `n`.

- Row `i` (starting from 1) contains exactly `i` stars.
- No extra spaces at the end of each line.

## Input
One integer `n` (`1 <= n <= 30`).

## Output
`n` lines forming the triangle.

## Example
Input
```
5
```

Output
```
*
**
***
****
*****
```
