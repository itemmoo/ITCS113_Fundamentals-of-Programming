# Mirror Number Triangle

Write a program that reads an integer `n` and prints a triangle of height `n`.

Row `i` (starting from 1) must be:

- Increasing numbers from `1` to `i`
- Then decreasing numbers from `i-1` down to `1`

Numbers must be printed **without spaces**.

## Input
One integer `n` (`1 <= n <= 9`).

## Output
`n` lines of the pattern.

## Example
Input
```
5
```

Output
```
1
121
12321
1234321
123454321
```
