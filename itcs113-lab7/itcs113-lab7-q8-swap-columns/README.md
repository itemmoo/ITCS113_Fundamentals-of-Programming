## Swap Two Columns

Write a program that swaps two columns of a matrix.

The program reads:
1. `n` rows and `m` columns
2. The `n × m` matrix
3. Two integers `c1` and `c2` (0-based column indices)

Swap column `c1` with column `c2` and print the updated matrix.

<hr>

**Input**
```
n m
(matrix n lines)
c1 c2
```

**Output**

Print the matrix after swapping columns.
