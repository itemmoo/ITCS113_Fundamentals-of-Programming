## Sum of Each Row

Write a program to compute the sum of each **row** of an input 2-D array.

The program reads the number of rows `n` and columns `m`, then reads the matrix values.
Finally, compute the sum of each row and print the results on one line.

<hr>

**Output format**

Print `n` integers, each followed by a space, in row order.

<hr>

**Case 1**

Sample input:
```
3 2
-8 7
1 0
41 8
```
Sample output:
```
-1 1 49 
```

**Case 2**

Sample input:
```
1 4
7 -4 5 9
```
Sample output:
```
17 
```
