## Fixed 2-D Array Indexing

This exercise practices **2-D array initialization** and **indexing**.

A fixed 3×3 matrix is defined in the program as:

```
1 2 3
4 5 6
7 8 9
```

The program reads two integers `r` and `c` (0-based indices) and prints the value at row `r` and column `c`.

<hr>

**Input**

Two integers `r c` where `0 <= r,c <= 2`.

**Output**

Print the value `A[r][c]`.

<hr>

**Case 1**

Sample input:
```
0 0
```
Sample output:
```
1
```

**Case 2**

Sample input:
```
2 1
```
Sample output:
```
8
```

**Case 3**

Sample input:
```
1 2
```
Sample output:
```
6
```
