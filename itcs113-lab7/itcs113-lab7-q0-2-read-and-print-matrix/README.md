## Read and Print a Matrix

Write a program that reads a 2-D array and prints it back.

The program first reads the number of rows `n` and columns `m`, then reads `n*m` integers.
Finally, print the matrix in the same shape:

- Print each row on its own line
- Print a space after each number

<hr>

**Case 1**

Sample input:
```
2 3
1 2 3
4 5 6
```

Sample output:
```
1 2 3 
4 5 6 
```

**Case 2**

Sample input:
```
1 1
-7
```

Sample output:
```
-7 
```
